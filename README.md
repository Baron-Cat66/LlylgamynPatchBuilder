# LlylgamynPatchBuilder

セガサターン版『ウィザードリィ リルガミンサーガ』用の
IPSパッチ生成ツールです。

ブラウザー上で完全オフライン動作します。
EXE・DLL・インストールは不要です。

## Version

Current release: v1.4

## Features

- 3シナリオ、全335件の名称編集
- Excelとのコピー・貼り付け
- IPSパッチ生成
- マカニト修正
- 元BINのSHA-256検証
- 外部通信なし

## Usage

詳細は `README.txt` を参照してください。

## Security

このツールはローカルHTMLとして動作します。
選択したBINファイルを外部へ送信する処理はありません。

ソースコード、検証資料、SHA-256を本リポジトリで公開しています。
