■ 使い方
1. LlylgamynPatchBuilder_v1.4.html をEdgeまたはChromeで開きます。
   HTMLファイルだけで動作します。インストールやサーバー起動は不要です。
2. 「Track 01を開く」で元のBINを選択します。ドロップでも開けます。
3. シナリオのタブを選び、未確定名・確定名を編集します。
4. 必要ならマカニト修正をチェックします。
5. 「IPSを生成・保存」でIPSをダウンロードします。
   保存先はブラウザーのダウンロード設定に従います。

■ Excelとのコピー・貼り付け
No.欄で行を選択できます。Ctrlで選択追加、Shiftで範囲選択。
「全行をコピー」「選択行をコピー」は No. / 未確定名 / 確定名 の3列です。
クリップボードへの直接コピーが使えない場合は表示されたテキストをCtrl+Cでコピーします。

名称欄への複数セルの直接貼り付け、または「貼り付け」画面に対応します。
- 3列：No. / 未確定名 / 確定名。No.で対象行を指定します。
- 2列：未確定名 / 確定名。選択した開始行から順番に適用します。
- 1列：選択した名称列へ、開始行から順番に適用します。
3列の見出し「No. 未確定名 確定名」（タブ区切り）は省略せず貼り付けても構いません。
貼り付けは文字コード・対象行・格納容量を全件確認してから一括適用します。
無効なデータがあれば、一部だけを変更することはありません。

名称プリセットとCSV入出力はありません。元BINから全335件を直接抽出します。
空欄、改行、タブ、絵文字などCP932で保存できない文字は使えません。
同じ名称は共有して格納します。長い名称を増やし過ぎて領域を超える場合はエラーを表示します。
「元に戻す」は直前の編集を取り消します（最大50回）。
「選択行を元に戻す」は選択した行を元BINの名称に戻します。

■ マカニト修正
「マカニト：魔法無効化率を無視する」はFC版と同じ修正です。
名称修正と併用可能です。未編集の状態ならマカニト修正だけのIPSも作成できます。

■ 対応する元ファイル
Track 01 / MODE1・2352 bytes/sector
Size: 17,917,536 bytes
SHA-256:
20881265584cd9e7310a3b62d1f98e2bca2f9a308d6b094fe9ecbfeb2765372f

サイズとSHA-256が一致しないBINは読み込みません。既にパッチ済みのBINも対象外です。
元BINを上書きする機能はありません。出力はIPSのみです。

■ 通信について
選択したファイルはブラウザー内だけで処理します。アップロードや外部通信はありません。
外部スクリプト、外部ライブラリー、EXE、DLL、インストーラーは含みません。
HTMLにはContent Security Policyを設定し、外部通信を禁止しています。

■ 検証結果
- 元Track 01のSHA-256照合、3シナリオ合計335件の読込。
- 各シナリオのS8B再圧縮と再展開で元データが一致。
- 元Track 01全7,618セクターのEDC/ECC再計算が元データと一致。
- マカニト修正のみの出力が既存の検証用IPSを適用したBINと一致。
- 既存の名称修正レビュー335件を適用し、生成IPSがバイト単位で一致：
  名称のみ 9,159 bytes / 名称＋マカニト 9,565 bytes。
- 検証用元BIN、名称プリセット、ゲームデータは配布ZIPに含みません。

■ 同梱ソース
core.js : 生成処理（S8B / CP932 / EDC/ECC / IPS）。
app.js : 画面操作。
template.html : HTMLテンプレート。
build.py : ソースから単一HTMLを生成するスクリプト（Python標準ライブラリーのみ）。
verify.cjs : 検証用のNode.jsスクリプト。元BINを引数に指定します。
VALIDATION.txt : 実施した検証と制約。
SHA256SUMS.txt : 配布ファイルのSHA-256。
